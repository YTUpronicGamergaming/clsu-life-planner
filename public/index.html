Add CLSU Life Planner to your device

Install it for a focused, app-like schedule view and quick access.

Chrome or Edge: choose the install icon in the address bar, or open the browser menu and select “Install app” or “Install this site as an app.”

iPhone or iPad: in Safari, tap Share, then “Add to Home Screen.”

Installation requires HTTPS. Some browsers do not offer app installation; the planner still works in a normal browser tab.
